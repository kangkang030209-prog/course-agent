# 大模型应用开发实战 —— 课程大纲

## 课程目标
本课程面向工程实践，目标是让学生掌握大模型应用的核心开发范式：
- 理解大模型（LLM）的基本原理与调用方式
- 掌握提示词工程（Prompt Engineering）的关键技巧
- 学会搭建 RAG（检索增强生成）知识问答系统
- 学会用 Agent 智能体 + 工具调用解决复杂任务
- 了解 MCP（模型上下文协议）在现代 AI 应用中的作用

## 适用对象
计算机相关专业高年级学生，需要具备 Python 编程基础。

## 先修要求
Python 基础、基本的网络编程概念。推荐先完成《Python 程序设计》课程。
